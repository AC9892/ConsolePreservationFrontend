# CPF Nintendo DSi 0.1.0 Alpha

This Windows x64 application runs a user supplied DSi firmware and NAND through a melonDS DS libretro backend. It opens into the original DSi interface after setup. It is an alpha: some built in applications and network features remain incomplete.

The ZIP contains no Nintendo BIOS, firmware, NAND, titles, games, saves, or console keys. Supply dumps from your own hardware in the first run window.

See INSTALLATION.md, CUSTOM_SHELL.md, BUTTON_LAYOUT.md, KEYBOARD.md, and KNOWN_ISSUES.md before use.
