# Known issues — public preview

- Original HOME rendering and selected applet workflows have been tested only with privately supplied materials and the pinned backend, not a fresh public setup on another PC.
- Fire Emblem: Awakening USA mounted in HOME and launched through initialization, opening movie, title, and character creation. Battle gameplay and save/reload are unverified. Pressing HOME at character creation caused fatal error 0xD8E007F7 (invalid handle during a wait call). This is unresolved.
- 3DSident installed, launched, accepted menu input, suspended, and closed through HOME. Its reported system values reflect emulator services and do not prove authentic complete firmware execution.
- Game Notes and Notifications returned to HOME; Friend List reached a missing-Mii prompt. Online functionality is unverified.
- No game CIA gameplay milestone, performance guarantee, full firmware boot, or multi-firmware manager is claimed. Firmware version is declared profile metadata; signatures are not authenticated.
- The public geometric artwork has no Nintendo device branding. Fast dragging, DPI changes, backend versions, touch alignment, and native window attachment need broader testing.
- Guided setup requires an original decrypted USA HOME CXI, a separate matching backup, and a separately extracted portable backend. It creates initial runtime settings and the private profile, but does not acquire console material or import a complete NAND. Other system applications remain user-supplied.
- Back up your private writable state. Failed installation can leave partial state for inspection; CPF does not delete existing saves or repair incomplete titles automatically.
