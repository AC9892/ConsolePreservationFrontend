# Third-party materials

Rust dependencies are pinned in Cargo.lock. The corresponding vendored packages and their original license files accompany the source archive. A dependency inventory records each package version, declared license, and registry provenance. Binary package notices are collected from those same vendored packages.

Azahar is not bundled. Users obtain and prepare it separately; its license and corresponding source are provided by its own distributor. The local private runtime and development shell images are excluded. Public shell PNGs are generated by release/generate-assets.py using original geometric primitives without reading development artwork.
